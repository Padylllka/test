# Помощник воспроизведения 超星 для Windows

Скрипт открывает видимый Chromium, запускает HTML5-видео, держит курсор браузера
над плеером и после события окончания нажимает кнопку следующего урока.
Поддерживает плееры во вложенных iframe. Вход в 超星 выполняется вручную
в отдельном профиле браузера; вход сохраняется между запусками.
Если в блоке есть видео и тест, после видео скрипт нажимает `下一节`,
оставляя тест без ответа. Кнопки ответов и отправки теста не нажимаются.
Если после видео открывается отдельная страница теста без видео, скрипт
распознаёт её и через 3 секунды ещё раз нажимает `下一节`, чтобы открыть
следующий блок. Повторного нажатия на ту же страницу теста не будет.
На каждом новом видео скрипт нажимает видимую кнопку воспроизведения плеера
(включая большую кнопку Video.js). Запуск работает и когда видео загружается
только после нажатия. Сообщение «Видео воспроизводится» появляется после начала
продвижения времени; во время уже идущего воспроизведения кнопка не нажимается.
Если появляется окно `当前章节还有任务点未完成，是否去完成?`, скрипт
нажимает `下一节` именно внутри этого окна и продолжает переход. Кнопка
`去学习` не нажимается. Повторное нажатие заблокировано, пока окно не исчезнет.
Поддерживаются надписи `下 一 节`, неразрывные пробелы, разбитый на элементы
текст и кнопки типа `input`.

## Установка

Нужен Python 3.10 или новее. В PowerShell в папке репозитория:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m playwright install chromium
```

## Запуск

Дважды нажми `start.bat` и вставь адрес курса. Либо в PowerShell:

```powershell
.\.venv\Scripts\python.exe watch.py --url "АДРЕС_КУРСА"
```

1. В открывшемся окне войди в аккаунт обычным способом.
2. Открой первое нужное видео **в той же вкладке**. Если сайт открыл новую
   вкладку, скопируй её адрес в исходную вкладку, за которой следит скрипт.
3. Оставь окно браузера видимым, плеер на экране, компьютер включённым.
   Скрипт раз в секунду наводит курсор браузера на видео. Физический указатель
   Windows он не блокирует: не пользуйся мышью поверх этого окна во время просмотра.
4. Для остановки нажми Ctrl+C в терминале или закрой окно браузера.

После окончания видео скрипт ищет кнопку, ссылку или элемент с точным текстом
`下一节`, `下一集`, `下一章`, `下一个视频`, `下一视频`, `Next video`, `Next lesson`
или `Следующее видео`. Скрытые и отключённые элементы пропускаются.
Если у кнопки другой текст или только значок, укажи её селектор:

```powershell
.\.venv\Scripts\python.exe watch.py --url "АДРЕС_КУРСА" --next-selector "button.next-lesson"
```

`button.next-lesson` — только пример, его надо заменить селектором настоящей
кнопки (F12 → выбрать элемент → Copy selector). Поиск выполняется и внутри iframe.
Не указывай общий селектор вроде `button`: он может нажать посторонний элемент.
Без найденной кнопки скрипт ждёт ручного перехода. Если после нажатия видео
не сменилось за 45 секунд, повторно кнопку не нажимает и пишет сообщение.

Если нестандартная кнопка запуска не распознаётся, укажи её точный селектор:

```powershell
.\.venv\Scripts\python.exe watch.py --url "АДРЕС_КУРСА" --play-selector ".vjs-big-play-button"
```

Поиск кнопки запуска выполняется во фрейме соответствующего плеера.
Неудавшийся запуск повторяется с интервалом не меньше 10 секунд.

Если окно с незавершёнными заданиями всё ещё не закрывается, запусти:

```powershell
.\start.bat --diagnose-notice
```

При запуске должна появиться версия `1.3.0`. Оставь уведомление открытым
на 30 секунд и скопируй строку `Диагностика уведомления` из терминала.
В ней только ограниченный список текстов и типов элементов интерфейса;
адреса страниц, cookies, значения полей и полный HTML не выводятся.

Можно использовать установленный Edge (`--channel msedge`) или Chrome
(`--channel chrome`) вместо загруженного Chromium. Не указывай личный профиль
браузера в `--profile`: используй отдельную папку, как задано по умолчанию.

## Границы работы и проверки

Скрипт работает с обычным HTML5-плеером. Он не отвечает на вопросы, не проходит
капчу и не подделывает прогресс или запросы об окончании просмотра. Встроенные
задания могут потребовать твоего участия. Зачёт просмотра определяется самим сайтом.
Если сайт запрещает переход к следующему блоку без теста, скрипт это ограничение
не обходит. Страницы тестов определяются по характерным заголовкам или адресу
фрейма задания; если разметка отличается, может потребоваться ручной переход.
Фоновая работа при свёрнутом окне, заблокированном Windows или спящем компьютере
не гарантируется.

Точная разметка кнопки в личном курсе ещё не проверена: доступ требует входа
в аккаунт. Автоматический поиск — начальный вариант, при необходимости нужен
селектор из страницы курса. Локальный интеграционный тест проверяет настоящее
воспроизведение видео в iframe, положение курсора и переход между двумя видео:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Профиль `.local/browser-profile` содержит сессию входа. Не передавай его другим.
Он и виртуальная среда исключены из Git. Адрес личного курса в коде не сохранён.

Для разработки используй существующий checkout: облачная задача уже изолирована,
создавать отдельный Git worktree не требуется.
